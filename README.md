# pipeline
1. Поднимается СУБД Postgres, используя Docker
2. Создается соответствующие схемы в init-файле - stg, ods, dm
3. Создаются два SQL-скрипта - на очистку данных от кривых/отсутствующих значений и на построение витрины в слое dm объединяющую информацию с исходных csv-файлов в очищенном виде
4. Выполняются запросы с помощью psycopg2 и sqlalchemy
5. Создаются функции на парсинг скриптов в папке, их построение и отработку
6. Поднимается сервис Apache Airflow
7. Создаются тестовые DAGs 
8. Создаются DAGs, автоматизирующие все этапы очистки данных и построения финальной витрины в слое dm
